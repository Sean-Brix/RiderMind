# Quiz Video Upload Fix - Seed Update

## What Changed

The seed now properly uploads quiz videos instead of just using direct Firebase URLs.

### Before (Not Working)
```javascript
videoUrl: 'https://firebasestorage.googleapis.com/v0/b/ridermind/o/animation-seed%2Fquiz%2Fquiz-1.mp4?alt=media'
videoPath: 'animation-seed/quiz/quiz-1.mp4'
```
❌ Videos stored in `animation-seed/` with direct URLs (doesn't work with your setup)

### After (Working)
```javascript
// 1. Create question first
const createdQuestion = await prisma.quizQuestion.create({ ... });

// 2. Download video from animation-seed
// 3. Re-upload to proper location
const videoData = await downloadAndUploadQuizVideo(
  'animation-seed/quiz/quiz-1.mp4',
  quiz.id,
  createdQuestion.id
);

// 4. Update question with proper URLs
await prisma.quizQuestion.update({
  where: { id: createdQuestion.id },
  data: {
    videoUrl: videoData.videoUrl,  // Proper Firebase URL
    videoPath: videoData.videoPath // quizzes/{quizId}/questions/{questionId}/...
  }
});
```
✅ Videos uploaded to `quizzes/{quizId}/questions/{questionId}/` (same as manual upload)

## How It Works

The new `downloadAndUploadQuizVideo()` function:
1. **Downloads** video from `animation-seed/quiz/` or `animation-seed/module/`
2. **Re-uploads** to proper location: `quizzes/{quizId}/questions/{questionId}/{timestamp}-{filename}.mp4`
3. **Returns** proper `videoUrl` and `videoPath` generated by Firebase Admin SDK

This mimics exactly what happens when you manually upload a video through the quiz editor!

## Why This Fix Works

1. **Same Process as Manual Upload** - Uses the same `uploadFile()` function from `utils/firebase.js`
2. **Proper Storage Paths** - Videos stored in organized `quizzes/{quizId}/questions/{questionId}/` structure
3. **Correct URLs** - Firebase Admin SDK generates proper download URLs with tokens
4. **Database Consistency** - `videoUrl` and `videoPath` match what manual uploads create

## Prerequisites

Make sure you have 20+ quiz videos in Firebase Storage at:
- `animation-seed/quiz/quiz-1.mp4` through `quiz-20.mp4` (or more)

The seed will randomly select from these and upload them to proper locations.
